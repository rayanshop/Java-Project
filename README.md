# 🚕 CAB BOOKING APP

## 📖 Description
A simple Java console-based application for booking cabs, managing riders and drivers, and tracking trips.

## 🚀 Features
- 👤 Add riders
- 🚕 Add cab drivers
- 📍 Find nearest available cab
- 🎫 Book trips
- 💰 Calculate fare
- ✅ Complete trips
- ❌ Cancel trips
- 📜 View trip history

## 🛠️ Technologies
- ☕ Java
- 🧩 OOP
- 📦 ArrayList
- ⌨️ Scanner

## 💰 Fare
Fare = Rs. 50 + (Distance × Rs. 15)
