🚕 Cab Booking App

A simple Java console-based Cab Booking Application that allows users to add riders and cab drivers, book cabs, complete or cancel trips, and view trip history.

🚀 Features

Add riders

Add cab drivers

View available/busy drivers

Automatically select the nearest available cab

Book a cab

Calculate trip fare

Complete or cancel trips

View trip history

Handles invalid input

🛠️ Technologies Used

Java

Object-Oriented Programming (OOP)

ArrayList

Scanner

⚙️ How It Works

The application uses different classes for riders, drivers, and trips. A rider can book a cab, and the system automatically selects the available driver who is closest to the passenger.

The fare is calculated using:

Fare = 50 + (Distance × 15)

▶️ How to Run

Install Java (JDK).

Save the code as Main.java.

Compile the program:

javac Main.java

Run the program:

java Main

📋 Menu Options

1. Add Rider
2. Add Cab Driver
3. Show Drivers
4. Book Cab
5. Complete Trip
6. Cancel Trip
7. Show Trip History
8. Exit

📚 OOP Concepts Used

Inheritance: Rider and CabDriver inherit from Person.

Encapsulation: Class data is kept private and accessed through methods.

Classes & Objects: Separate classes represent people, drivers, riders, and trips.

Methods: Different operations are implemented using methods.
